# Bosswright LM downloads

Bosswright LM picks, downloads and runs open AI models on your own computer, with
Bosswright Cloud for bigger models when you need them. Free for local use.

**Download page:** https://bosswright.dev/download
**All versions:** [Releases](https://github.com/MachineDogDev/bosswright-lm-releases/releases)

| Computer | File |
|---|---|
| Windows 10/11, 64-bit | `Bosswright-LM-<version>.msi` (installer) or `-Windows.zip` (portable) |
| Mac with Apple chip | `-macOS-arm64.zip` |
| Mac with Intel | `-macOS-x64.zip` |
| Linux x64 / ARM64 | `-Linux-x64.tar.gz` / `-Linux-arm64.tar.gz` |

This repository only holds the installers and release notes. Bosswright LM is made by
MachineDog Holdings, LLC · support@bosswright.dev. Third-party licenses ship inside each
download (`licenses` folder) and in the app under Settings > About.
